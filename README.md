# Куди піти?☕️

Django-сайт з улюбленими місцями для відпочинку. Лабораторна робота курсу ВПА2026.

## Як запустити

1. Створіть та активуйте віртуальне оточення:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

2. Встановіть залежності:

   ```bash
   pip install -r requirements.txt
   ```

3. Застосуйте міграції (потрібні лише для вбудованих таблиць Django, самі місця зберігаються в сесії):

   ```bash
   python manage.py migrate
   ```

4. Запустіть сервер:

   ```bash
   python manage.py runserver
   ```

5. Відкрийте http://127.0.0.1:8000/ у браузері.

## Примітка

Список місць зберігається в сесії браузера (`request.session`), тому в різних браузерах/вкладках-інкогніто будуть різні списки.
